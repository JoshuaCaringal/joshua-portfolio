# Carina — Systems & Automation Portfolio

Premium red-and-white portfolio for practical digital systems, automation, dashboards, workflows, and internal business tools.

## Tech stack
React, TypeScript, Vite, Tailwind CSS, Framer Motion, GSAP, Lucide React, React Router.

## Commands
```bash
npm install
npm run dev
npm run build
```

## Project screenshots
- QR Timesheet: `src/assets/projects/qr-timesheet/`
- Expense Tracker: `src/assets/projects/expense-tracker/`
- E-Learning: `src/assets/projects/elearning/`
- Automation: `src/assets/projects/automation/`

Use filenames such as `01.png`, `02.png`, `03.png`, `04.png`. Supported: PNG, JPG, JPEG, WEBP. Vite `import.meta.glob` auto-loads project screenshots. Missing images show designed placeholders.

## Certificates
Images: `src/assets/certificates/`. Metadata: `src/data/certificates.ts`.

## Editing
Projects: `src/data/projects.ts`  
Skills: `src/data/skills.ts`  
Profile/contact: `src/data/profile.ts`

## Vercel
Framework: Vite. Install: `npm install`. Build: `npm run build`. Output: `dist`. SPA rewrites are configured in `vercel.json`.
